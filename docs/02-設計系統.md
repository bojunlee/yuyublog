# 第二階段：設計系統

方向：**高質感旅遊雜誌 × 個人生活風格**。攝影是主角，文字像雜誌一樣有層次，介面元素克制。
所有數值都定義在 `assets/css/site.css` 最上方的 `:root`，改一個地方全站一起變。

## 色彩

| Token | 色碼 | 用途 |
| --- | --- | --- |
| `--paper` | `#f6f1e8` | 頁面底色（奶油紙張） |
| `--paper-2` | `#efe6d8` | 區塊底色、圖片載入前的佔位 |
| `--surface` | `#fffdf9` | 卡片、表單 |
| `--ink` | `#1b2630` | 主要文字、主要按鈕（深海墨色） |
| `--ocean` / `--ocean-deep` | `#1f5673` / `#133a50` | 旅遊分類、足跡區塊、頁尾 |
| `--sunset` | `#a54e2c` | 強調色：小標、重點按鈕、引言線（文字對比 ≥ 4.5:1） |
| `--c-stay` / `--c-life` | `#2f7468` / `#a65665` | 度假、生活分類 |

漸層只用在照片上的暗角（確保白字可讀），不用在按鈕或背景。

## 字體

| 角色 | 字體 | 用在 | 怎麼載入 |
| --- | --- | --- | --- |
| 品牌字 | Noto Serif TC 900 | 「魚魚出去玩」 | 只下載「魚出去玩」四個字 |
| 標題 | Noto Serif TC 700 | 頁面標題、文章標題 | 只下載頁面上用到的字（`assets/js/lib/fonts.js`） |
| 內文 | 裝置內建：蘋方、思源黑體、微軟正黑體 | 內文、介面 | 不用下載 |
| 手寫感 | 霞鶩文楷 TC | 標語、引言、手寫小語 | 只下載頁面上用到的字 |
| 英文小標 | Cormorant Garamond Italic | 區塊上方的 *Latest Stories* 等 |
| 簽名 | Allura | 「Yuyu goes out」 |

書法類字體（Zhi Mang Xing、Ma Shan Zheng 等）缺少繁體「魚」「風」，實測會混字，所以不採用。

**為什麼中文字型要「用多少載多少」**：原本完整載入三套中文字型，首頁光字型就 3.5 MB、51 個檔案，
手機在慢速網路下主要內容要 26 秒才出現。改成內文用裝置字型、標題與手寫字只載入用到的字之後，
首頁總量降到約 1.8 MB，Lighthouse 實測主要內容 3.2 秒出現（2026-10-10，見 `scripts/audit.mjs`）。

**品牌字標**：粗襯線「魚魚出去玩」＋ 斜放的手寫簽名「Yuyu goes out」＋ 線條小魚標誌，像雜誌刊頭。

## 間距、形狀、版面

- 間距以 4px 為基準：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128
- 區塊上下留白：`clamp(64px, 5vw + 40px, 120px)`
- 內容最大寬度 1240px；文章閱讀欄 700px（每行約 32–36 個中文字）
- 圓角克制：6 / 10 / 16px，只有按鈕和標籤是膠囊形
- 照片比例：卡片 4:3、大卡 16:11、分類 3:4、封面故事 5:4、關於 4:5

## 元件

按鈕（實心 / 強調 / 外框 / 淺色）、分類標籤、文章卡片（標準 / 大 / 橫式）、分類切換 chips、
搜尋框、骨架載入、空狀態、錯誤狀態、Toast、燈箱、資訊卡（餐廳 / 花費 / 行程 / 交通）。

## 動態規則

| 類型 | 規則 |
| --- | --- |
| 緩動 | 全站統一 `cubic-bezier(.22,.61,.36,1)` |
| 時間 | 互動 160ms、狀態 320ms、進場 700ms、主視覺 1400ms |
| 主視覺 | 照片從 1.08 倍慢慢縮回原位，文字依序淡入（每行間隔 120ms） |
| 捲動淡入 | 只動一次，只用透明度＋往上 16px，同一組最多錯開 4 層 |
| 卡片 | 滑過時照片放大 4.5%、標題出現底線 |
| 頁面轉場 | 支援的瀏覽器使用 View Transitions 淡入淡出 240ms |
| 足跡地圖 | 路線 2.6 秒畫完；國家上色、圖釘彈出與路線同步；地圖縮放 650ms；只有最新一站會持續脈動 |
| 減少動態 | `prefers-reduced-motion` 時全部關閉，內容直接顯示（有自動測試） |

不使用：持續漂浮、旋轉、視差捲動、每個元素都飛入。

## 頁面規劃

| 頁面 | 檔案 | 重點 |
| --- | --- | --- |
| 首頁 | `index.html` | 主視覺（深）→ 分類（奶油，錯落排列）→ 封面故事（淺海藍，圖文交疊）→ 最新文章（奶油，一大三小三欄）→ 照片日記（夜色拼貼）→ 關於魚魚（沙色，拍立得拼貼）→ 足跡（深海，小地圖＋環遊世界進度＋願望郵票）→ 結尾引言。手機上分類、文章、照片、願望改成左右滑動列 |
| 文章列表 | `posts.html` | 分類切換、搜尋、載入更多；網址會記住篩選（`?cat=food&q=京都`） |
| 文章 | `post.html?id=…` | 大封面、置中標題卡、導言、內文、照片集輪播、旅行小抄、喜歡、分享、相關文章 |
| 旅行足跡 | `footprints.html` | 互動世界地圖：依造訪順序畫出旅行路線、國家依序上色；圖釘固定 44px 點擊範圍；縮放按鈕、雙指縮放、拖曳；點國家放大並顯示資訊卡；手機一開始就放大到去過的國家；國家快速按鈕 |
| 關於魚魚 | `about.html` | 照片、介紹、我的故事、旅行理念、喜歡的事物、社群連結 |
| 後台 | `admin/` | 手機優先，見 `04-魚魚使用說明.md` |
